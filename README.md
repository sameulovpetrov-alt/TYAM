# КРАЙ: Полынь

Кубическая survival-игра о первой неделе на холодном северном острове. Исследуй побережье, собирай древесину и камень, делай снаряжение, следи за жаждой и построй убежище до первой ночи.

В репозитории есть **играбельный браузерный прототип** с изометрическим voxel-миром и самостоятельная **C++-версия игры для терминала**. Игровые правила и консольный executable находятся в `game/`.

Публичная браузерная версия: [sameulovpetrov-alt.github.io/TYAM](https://sameulovpetrov-alt.github.io/TYAM/). Сборка для GitHub Pages — `npm run build:pages`.

## Браузерный прототип

```bash
npm install
npm run dev
```

Открой адрес Vite, чтобы сразу войти в мир. Состояние мира локальное; серверная часть для мультиплеера пока не подключена.

### Управление

| Клавиша | Действие |
| --- | --- |
| `W A S D` / стрелки | Перемещение |
| `Shift` | Бег |
| Клик по ресурсу | Выбрать цель |
| `E` | Добыть выбранный ресурс |
| `1–8` | Выбрать предмет быстрого доступа |
| `C` | Крафт и строительство |
| `I` | Рюкзак |
| `M` | Карта |
| `F` / `G` | Съесть ягоды / выпить воды |
| `H` | Использовать повязку |
| Клик по земле с выбранной постройкой | Разместить костёр, фундамент или стену |
| `Esc` | Пауза |

На телефоне доступны экранные кнопки движения и взаимодействия.

## C++-игра

Нужен компилятор с поддержкой C++17. Вариант без дополнительных библиотек:

```bash
g++ -std=c++17 -O2 -Wall -Wextra -pedantic game/src/main.cpp -o krai-survival
./krai-survival
```

Или через CMake:

```bash
cmake -S game -B build
cmake --build build
./build/krai-survival
```

### Управление в C++-версии

`W A S D` — идти, `RUN` — короткий рывок на две клетки в последнем направлении, `E` — собрать ресурс, `C` — меню крафта, `B` — постройка, `F` — еда, `G` — вода, `H` — лечение, `1–8` — быстрый доступ, `I` — рюкзак, `T` — факел, `Q` — выход.

Терминальная версия работает без игровых библиотек: мир генерируется при запуске, а ресурсы, здоровье, голод, жажда, рецепты и размещение построек реализованы на C++. Ввод пошаговый: введи команду и нажми Enter.
