# TYAM — Общение на твоей орбите 🪐

Лендинг платформы **TYAM** — сервиса для общения в реальном времени: голосовые комнаты, трансляции 1080p 60fps и сообщества для игр, учёбы, работы и отдыха.

Сделан по мотивам референса LOLKA, но с собственным именем **TYAM**, градиентным логотипом и живым мокапом **TYAM Launcher** вместо старого скриншота.

## ✨ Что на сайте

- **Шапка** — логотип-планета, навигация (Дорожная карта, Возможности, Вопросы, Скачать), мобильное меню
- **Hero** — гигантский градиентный **TYAM** с анимированным переливом, орбитальным кольцом и парящей планетой
- **TYAM Launcher (интерактивный мокап)** — точная копия лаунчера со скриншота:
  - вкладки **Главная / Обновления / Настройки** — всё кликается
  - журнал обновлений и рабочие тоглы настроек
  - кнопка **«Запустить TYAM»** с анимированным прогрессом запуска
  - живой эквалайзер, статус-бар «Сеть доступна»
- **Почему TYAM?** — 3 карточки: качество, стабильность, бесплатно и без VPN
- **Бегущая строка** возможностей
- **Возможности + статистика** — голос, стримы, серверы, кастомизация, приватность, оверлей
- **Дорожная карта** — таймлайн Q4 2026 → Q3 2027
- **FAQ** — аккордеон из 6 вопросов
- **Скачивание** — кнопки Windows / macOS / Linux / Web с тостом загрузки
- **Футер** — ссылки и живой статус «Все системы в норме»

## 🎨 Дизайн

- Тёмная тема `#050508` + точечная сетка как в референсе
- Фирменный космический градиент: `лаванда → фиолет → индиго → циан`
- Шрифты: **Unbounded** (заголовки) + **Inter** (текст)
- Анимации: reveal при скролле, перелив градиента, орбиты, marquee, эквалайзер

## 🛠️ Технологии

- React 19 + Vite + Tailwind CSS 4
- Lucide-иконки
- TypeScript

## 🚀 Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```
